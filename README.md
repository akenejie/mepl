## Overview

Material Equivalence Public License (MEPL) は、情報の非商品化を目的として設計されたライセンスです。

情報は複製されても減少しません。ある人が情報のコピーを他者に渡しても、元の人がその情報を失うことはありません。

MEPLは、この性質に着目し、情報の複製、提供、アクセス、利用権そのものを経済的な対価と交換することを認めません。

一方、物理的な物体や資源には、製造、輸送、保管、通信、計算などの実際のコストが存在します。また、人間による労働やサービスにも対価が発生します。

MEPLは、これらを情報そのものの対価と区別します。

**情報は共有する。物体と資源には対価を認める。創造は創造主体自身の目的として存在する。**

これがMEPLの基本原則です。

## Core Principles

MEPLは、以下の原則に基づいています。

### 1. Information Is Not a Commodity

情報の複製や伝達によって、元の情報が失われることはありません。

そのため、情報のコピー、ダウンロード、アクセス、利用権、機能の提供など、それ自体に対して金銭その他の経済的対価を要求することを禁止します。

情報の開発費、研究費、品質、利便性、利用価値などを理由とする料金も、情報そのものの対価であれば認められません。

### 2. Physical Objects and Resources Are Different

物理的な物体や資源は情報とは異なります。

物体の製造、輸送、保管、通信帯域、ストレージ、コンピューティング資源などについては、実際の物理的コストに相当する対価を認めます。

また、設置、カスタマイズ、保守、コンサルティング、教育など、情報そのものの価格ではない労働やサービスへの対価も認めます。

### 3. Creation as an End in Itself

情報を創造することは、創造主体自身の目的として成立します。

創作者が自らの創作活動を続けるために、他者から任意の支援を受けることは歓迎されます。

寄付者は顧客ではありません。

寄付とは情報を購入する行為ではなく、創造活動を支援し、その内側に参加する意思の表明です。

### 4. Acts, Not Categories of Actors

MEPLは、利用者の属性ではなく、利用行為を規制します。

個人、法人、営利企業、非営利団体、政府機関など、利用者の法的地位や組織形態は許諾の条件ではありません。

営利企業による利用、社内業務への導入、製品やサービスへの組み込みも、それ自体は禁止されません。

禁止されるのは、情報そのものを商品化する行為です。

## What MEPL Allows

MEPLの条件を遵守する限り、以下の行為が認められます。

- 作品の無償利用、実行、複製、改変。
- 作品および改変版の無償配布、公衆送信、公開。
- 個人・法人を問わない利用。
- 営利企業による社内利用および事業への導入。
- 作品を組み込んだハードウェアや物理的製品の販売（第3条の条件に従う場合）。
- 実際の物理的資源のコストに相当する料金の請求。
- インストール、カスタマイズ、保守、コンサルティング、教育などのサービス提供。
- 完全に任意かつ無条件の寄付の受領。
- MEPLの条件に従った改変版の作成および共有。

## What MEPL Prohibits

以下は、原則として禁止されます。

- 有料ダウンロード、有料コピー、有料ライセンス。
- 情報そのものに対するサブスクリプション料金。
- 有料アクセス、機能アンロック料金、利用権料金。
- 情報の提供、アクセス、ダウンロード自体を収益化する広告や紹介料。
- 開発費、研究費、品質、利便性、利用価値などを理由とした情報対価の請求。
- バンドル価格、会員費、必須寄付、第三者を介した請求などによる商品化の迂回。
- 寄付の有無に基づく利用権、優先順位、特別待遇の差別化。
- 改変版への情報非商品化条件やソース公開義務の適用を回避すること。
- 利用者が作品を削除したり、改変版を実行したりすることを技術的に妨げること。

## Commercial Use

MEPLは、営利活動そのものを禁止するライセンスではありません。

企業は、MEPLの作品を自社の事業に利用したり、自社製品やサービスに組み込んだりできます。

ただし、提供する情報そのものに対価を設定することはできません。

例えば、以下のような活動が考えられます。

| Activity | MEPL |
|---|---|
| Internal business use | Allowed |
| Paid software downloads | Prohibited |
| Paid API access | Prohibited |
| Software subscription fees | Prohibited |
| Hardware incorporating the Work | Allowed under conditions |
| Computing resource cost recovery | Allowed under conditions |
| Installation and maintenance services | Allowed |
| Consulting and training | Allowed |
| Voluntary donations | Allowed |
| Advertising on the Work's distribution page | Prohibited |
| Advertising on content created using the Work | Generally allowed |

### Physical Exception

作品を組み込んだ物理的製品を販売する場合、その価格は、作品を含まない同等の物理的仕様の製品の一般市場価格、または物理的な製造・流通コストによって合理的に説明できるものでなければなりません。

AI推論、ストレージ、通信帯域などの物理的資源を提供する場合も、実際のコストに相当する対価を請求できます。

これらの例外を利用して情報の価格を間接的に請求することは認められません。

詳細はLICENSEのArticle 3を参照してください。

## Source Disclosure and Share-Alike

MEPLでは、作品の自由な改変と共有を維持するため、ソースコードの公開義務を定めています。

### Modified Versions

改変版を配布する場合、対応する機械可読形式のソースコードを、MEPLの条件に従い無償で提供しなければなりません。

### Network Use

改変版がネットワーク経由でユーザーと対話する機能を持つ場合、ユーザーが対応ソースコードを無償で取得できる機会を提供しなければなりません。

### Web Services

Webサービスとして作品を利用する場合、改変版の配布・公衆実行や、作品から派生したデータの提供について、第5条に定めるソースコード提供義務が適用されます。

改変版にも、情報の非商品化条件とソースコード公開義務が引き継がれます。

MEPLの作品を改変して共有する場合、原則としてMEPLの条件を維持しなければなりません。

詳細はLICENSEのArticles 5 and 7を参照してください。

## User Control and Anti-Lockdown

MEPLは、利用者が自分の所有する機器と、その機器上で動くソフトウェアを自ら管理できることを重視します。

作品がハードウェアに組み込まれて提供される場合、以下の義務が適用されます。

- 利用者が作品を容易に削除、アンインストール、または無効化できること。
- 利用者による改変版のインストールおよび実行を技術的に妨げないこと。
- 改変版をインストールして実行するために必要な情報を提供すること。

ソースコードが公開されていても、メーカーの秘密鍵や技術的制約によって改変版を実行できないのであれば、利用者の自由は実現されません。

MEPLは、ソースコードへのアクセスだけでなく、実際に改変して実行する自由も保障しようとします。

詳細はLICENSEのArticle 6を参照してください。

## Article 11: Abolition of Copyright Law and Disarmament

Article 11は、MEPLの長期的な思想と、独自の権利移行メカニズムを定めています。

MEPLは、現行の知的財産法が情報の独占と商品化を認めている状況に対する、一時的な防御手段として設計されています。

将来、国家または国際社会が知的財産法を廃止し、情報の独占や情報への課金を法的に無効化した場合、MEPLはその役割を終えます。

その時点で、作品はGNU Affero General Public License Version 3 (AGPLv3) の下に置かれ、MEPLは法的ライセンスとしてではなく、思想的な宣言として残ることを想定しています。

また、現行制度の下でも、知的財産法の正当性を否定するConversion Modifierは、MEPLの作品をAGPLv3のソフトウェアと密接に結合して公開するための特別な許諾を受けることができます。

この仕組みでは、情報の商品化が発生した場合、Conversion Modifier自身への許諾が遡及的に失効する一方、受領者に元の権利者から直接与えられたAGPLv3上の権利は維持されます。

この独自の仕組みは、情報の商品化を防ぎながら、利用者の自由を不必要に制限しないことを意図しています。

詳細はLICENSEのArticle 11を参照してください。

## Philosophy

MEPLが目指すのは、創造活動を経済的な取引から切り離し、情報を誰もが自由に利用・改変・共有できる状態を実現することです。

情報を受け取るためにお金を払う必要はありません。

情報を複製するために許可を求める必要もありません。

創造活動を支援したい人は、寄付やその他の形で創造主体を支援できます。

企業は情報そのものを売ることなく、物理的な製品、資源、労働、サービスを通じて経済活動を行うことができます。

そして、いつか情報の独占を正当化する制度そのものが不要になったとき、MEPLもまた、その役割を終えることを想定しています。

## 学習は伝達か — 自由エネルギー原理からの一問

「では、伝統的な学校での一方向的な講義も情報対価化なのか？」

この問いに対して、自由エネルギー原理(FEP)は逆問を投げかける。**学習って、伝達ですか？**

FEPの見立てでは、生物が学習するとき、外部から情報が「注入」されるのではない。学習者自身が予測を立て、その予測誤り(自由エネルギー)を最小化するために、自らの生成モデルを更新する。講義を一方的に聞いていても、学習者の行動(質問、実験、予測)がなければ、モデルは更新されない。伝達されたのは音波であって、学習ではない。

つまり「講義で学ぶ」という体験は、講義という情報の伝達ではなく、学習者自身が能動的に推論し、誤りを修正する過程として起こる。教師が売れるのは伝達ではなく、学習者の推論過程に応答する労働(質問への回答、個別の実演)である。

一方向的な講義の対価化は、学習という起きないはずの現象を売っている。双方向の対話の対価化は、実際に行われた労働の対価である。この差が、MEPLが情報の対価化を禁じながら労働の対価を認める理由である。

この帰結として、対価が成立する取引では、販売先の人間の側にも行為が発生している。モノを受け取るために手を伸ばすこと、対面のために移動すること、問いを発すること——いずれも、受領者自身の運動がその後のやり取りを変える行為である。何も行為しない人間に届くのは一方向的な伝達だけであり、それは感覚の受動的な受容であって、行為ではない。双方向の応答ごとの対価が等価交換であるのは、販売元の労働と販売先の行為が互いに相手の次の状態を生み出し合う閉じた環を形成しているからである。

MEPLの条文は、この哲学を持ち出さずに機械的な基準(双方向の応答ごとの対価)として実装する。しかし思想としては、この問い——**学習は伝達か、それとも推論か**——こそが、情報の対価化を禁じる根拠の深部にある。

**Is learning transmission?**

Under the Free Energy Principle, a learner is not a container into which information is poured. Learning happens when the learner's own predictive model encounters errors it cannot ignore and updates itself. A one-way lecture does not cause learning; the learner's active engagement does. What a teacher can sell is not the transmission but the labor of responding to each learner's own process of inference. This is why MEPL prohibits the commodification of information while permitting compensation for labor — and why the distinction between a broadcast and a conversation matters.

As a consequence, an act also occurs on the buyer's side in any transaction where consideration is valid: reaching out to receive a thing, traveling to be present, or voicing a question — each is an act of the recipient's own that changes what follows in the exchange. What reaches a person who performs no act is one-way transmission alone — passive sensory reception, not an act. The per-response compensation is equivalent exchange because the seller's labor and the buyer's act form a closed loop, each generating the other's next state.
